What's in a sysdiagnose — and what to ask about it

An Apple sysdiagnose is a few hundred megabytes of mostly-binary diagnostic state. This page maps it into categories, names the files each one lives in, and gives you prompts you can paste straight into Claude Code to interrogate them.

No device data on this page. Everything below describes the structure of a sysdiagnose, not the contents of any particular one. Nothing here is read from a case, so this page is safe to publish. Your extracted case stays local and gitignored.

Part of the Sysdiagnose Analysis Framework. Module names in monospace are SAF parsers — run them with sysdiag -c <case> parse <module>. Entries marked no parser are handled by the residual sweep instead.

Want the whole archive converted and indexed before you start asking? Use the local analysis prompt — paste it into Claude Code on the Mac itself and it runs extract → convert → parse → index unattended.

Capture a sysdiagnose: macOS — sudo sysdiagnose, or ⌘⌥⌃⇧.  ·  iOS — hold both volume buttons + side button for ~1.5s, then Settings › Privacy & Security › Analytics & Improvements › Analytics Data.
